角色库（用户培养的角色）

展示「用户可创建、培养多个独立人格与独立记忆的 AI 角色」。已预置 3 个演示角色。

创建流程（演示）

按 demo 脚本：上传人物照片 → 输入姓名/背景/性格 → 设置关系与说话方式 → 设置行为边界。

  1. 上传一张人物照片，作为角色形象参考（本地预览，不上传服务器）。
  2. 输入角色姓名、背景与性格。
  3. 设置角色与你的关系、希望它如何说话与陪伴。
  4. 设置行为边界（禁止话题）。
  5. 保存即进入角色库，可对话 / 协作 / 授权记忆。

语音唤醒 & 角色对话

选择已创建角色，进行文字或语音对话；角色拥有独立声音与风格，并能记住之前的交流。

提示：点「🎙 语音输入」可直接用麦克风说话（Chrome 支持最佳）；「🔊 语音播报」会让角色用语音念出回复。

多角色协作

演示「用户授权下多角色共同回应」。输入一个问题，三个预设角色分别从各自角度回答。

记忆权限与角色成长

核心差异化功能：用户告诉某角色一件私事 → 默认仅该角色可访问 → 用户主动授权其他角色 → 被授权角色即可调用。

演示步骤：在「② 语音对话」里对知心朋友说句私事并点该条消息的「＋记忆」；回到此处把它授权给人生导师；再切到导师对话问「你还记得我之前说的吗」，导师即可召回。

图像模式（多模态示意）

上传一张照片，选择角色，生成「人格条件化」的文案（呼应 mood_pipeline：图像→情感→人格文案）。浏览器内为示意生成，接入视觉模型后即可真实理解图像。

说明：本页面为产品概念原型，用于演示交互与价值主张。对话回复由前端「人格模板引擎」生成（部分后台逻辑为简化模拟），符合 Spec 中「MVP 阶段部分后台逻辑可简化」的原则。接入真实大模型（LLM + TTS + 视觉模型 + 向量记忆库）后即可作为可上线 MVP。
